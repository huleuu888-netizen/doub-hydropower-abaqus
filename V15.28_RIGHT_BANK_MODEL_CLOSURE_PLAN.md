# V15.28 Right Bank Model Closure Plan

## Audit conclusion

The V15.28 right bank seepage closure model has achieved preliminary engineering consistency with the Duobu Hydropower Station geological documents. The main remaining work is not material definition, but spatial correspondence and traceability between the finite element model and engineering geological design.

## Required modifications before S03-S07 degradation analysis

### 1. Right bank curtain geometry verification

- Verify curtain length, depth and spatial position against the engineering design scheme.
- Add a coordinate-based audit table:
  - design location
  - FE model location
  - deviation
  - acceptance status

### 2. Geological zoning traceability

The current right bank representation uses equivalent seepage zones:

- strong unloaded rock
- weak unloaded rock
- deep unloaded rock
- fresh granite
- deep crack zone

The model should add documentation explaining the equivalence relationship with geological unloading zones.

### 3. Key weak layer verification

Check spatial distribution of:

- Q3al-II
- Q3al-IV1/Q3al-IV2
- Q4al coverage layers

Confirm that the finite element locations correspond to geological sections.

### 4. Seepage boundary audit

Before degradation cases:

- verify upstream/downstream water head boundary
- verify initial pore pressure
- verify drainage boundary
- record all boundary sets

### 5. Recommended workflow

1. Complete V15.28 engineering consistency audit.
2. Freeze baseline model.
3. Run S03 global permeability degradation cases.
4. Run S05 random field heterogeneity cases.
5. Analyze transition zones and weak-zone migration.

## Status

V15.28 baseline should not be directly modified during degradation studies. All changes should be versioned as new audited releases.
